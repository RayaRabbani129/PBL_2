## 1. PENDAHULUAN
MATCHGOTIM adalah sistem berbasis website untuk player yang ingin mencari lawan, mengelola tim, melihat jadwal pertandingan, serta memantau statistik tim dalam satu platform.

Buku petunjuk ini dibuat untuk membantu player menggunakan MATCHGOTIM dengan alur sesuai tampilan aplikasi saat ini.

## 2. PROSEDUR

### 2.1 Login atau Register Akun Baru
Sebelum menggunakan MATCHGOTIM, Anda harus memiliki akun.

1. Buka aplikasi browser di komputer atau handphone.
2. Ketik alamat URL MATCHGO pada bar alamat.
3. Pada halaman awal, Anda akan melihat tombol `Daftar` dan `Masuk`.
   - Gambar 1.1: Halaman awal MATCHGO

#### Jika belum memiliki akun
1. Klik tombol `Daftar` di kanan atas.
2. Isi form registrasi:
   - Nama Lengkap
   - Email
   - Password
   - Konfirmasi Password
3. Klik tombol `Daftar` untuk menyimpan akun.
   - Gambar 1.2: Form Daftar Akun Baru

#### Jika sudah memiliki akun
1. Klik tombol `Masuk`.
2. Isi form login:
   - Email terdaftar
   - Password
3. Klik tombol `Masuk`.
   - Gambar 1.3: Form Masuk LOGIN
4. Jika lupa password, gunakan fitur `Lupa Password` untuk mengatur ulang.

Setelah berhasil masuk, Anda akan diarahkan ke halaman `Dashboard`.

### 2.2 Dashboard
Halaman Dashboard adalah pusat informasi utama player.

Di halaman ini, Anda dapat melihat:
- Statistik tim
- Performa tim (menang, kalah, seri)
- Aksi cepat seperti `Cari Lawan`, `Kelola Tim`, `Hitung Biaya Split`, `Edit Profil`
- Jadwal pertandingan mendatang
- Riwayat pertandingan terakhir
- Tombol akses cepat ke `Matchmaking`

#### Langkah menggunakan dashboard
1. Periksa ringkasan statistik tim pada bagian atas.
2. Gunakan tombol aksi cepat jika ingin langsung menuju:
   - `Cari Lawan` → untuk matchmaking
   - `Kelola Tim` → untuk membuka halaman Tim Saya
   - `Hitung Biaya Split` → jika ingin membagi biaya pertandingan
   - `Edit Profil` → untuk memperbarui data akun
3. Baca informasi pertandingan dan notifikasi terbaru.
   - Gambar 1.4: Tampilan Dashboard

### 2.3 Menu Navigasi Utama
Di sisi kiri, terdapat menu navigasi utama yang biasanya berisi:
- Dashboard
- Tim Saya
- Jadwal / Schedule
- Matchmaking
- Pertandingan
- Profil
- Notifikasi

Gunakan menu ini untuk berpindah antar halaman dengan cepat.

### 2.4 Tim Saya
Sebelum mengajukan tantangan lawan, pastikan Anda sudah memiliki tim.

#### Cara membuat dan mengelola tim
1. Pilih menu `Tim Saya`.
2. Jika belum ada tim, klik tombol `Buat Tim`.
3. Isi nama tim dan informasi tim.
4. Tambahkan anggota tim jika diperlukan.
5. Atur jadwal tim di halaman `Jadwal` jika tersedia.

#### Manfaat halaman Tim Saya
- Melihat anggota tim
- Memantau status kesiapan tim
- Menyimpan data tim untuk pertandingan

### 2.5 Matchmaking
Halaman `Matchmaking` adalah tempat mencari lawan dan mengajukan tantangan.

#### Langkah mencari lawan
1. Masuk ke menu `Matchmaking`.
2. Gunakan fitur pencarian atau filter untuk memilih lawan yang cocok.
3. Lihat daftar tim lawan yang tersedia.
4. Klik tombol `Challenge` atau `Tantang` pada tim yang ingin Anda hadapi.
   - Gambar 1.5: Halaman Matchmaking

#### Mengelola tantangan
- `Incoming` → melihat tantangan yang masuk ke tim Anda
- `Outgoing` → melihat tantangan yang telah Anda kirim
- Terima atau tolak tantangan langsung di halaman `Incoming`
- Batalkan tantangan yang sudah dikirim di halaman `Outgoing`

#### Catatan penting
- Pastikan tim Anda sudah dibuat di menu `Tim Saya` sebelum mencari lawan.
- Jika tim belum dibuat, Anda tidak dapat mengajukan tantangan.

### 2.6 Pertandingan
Halaman `Pertandingan` menampilkan daftar semua jadwal dan hasil pertandingan tim Anda.

#### Fitur utama halaman Pertandingan
- Melihat status pertandingan: `Terjadwal`, `Selesai`, atau `Dibatalkan`
- Melihat detail lawan, waktu, dan tempat pertandingan
- Menginput skor pertandingan jika diminta
- Menerima atau menolak challenge dari pertandingan

#### Cara menggunakan halaman Pertandingan
1. Pilih menu `Pertandingan`.
2. Pilih pertandingan yang ingin dilihat detailnya.
3. Di halaman detail, periksa informasi pertandingan seperti lawan, jadwal, dan skor.
4. Jika diperlukan, klik tombol `Batalkan` untuk membatalkan pertandingan.
5. Masukkan hasil skor pada form yang tersedia jika pertandingan sudah selesai.
   - Gambar 1.6: Halaman Pertandingan

### 2.7 Profil
Halaman `Profil` berguna untuk memperbarui data akun Anda.

#### Data profil yang dapat diperbarui
- Nama lengkap
- Email
- Nomor telepon
- Foto profil
- Password

#### Langkah memperbarui profil
1. Pilih menu `Profil`.
2. Klik `Edit Profil` atau menu serupa.
3. Isi data terbaru yang ingin diperbarui.
4. Simpan perubahan.
   - Gambar 1.7: Halaman Profil

### 2.8 Notifikasi
Notifikasi menampilkan pesan penting seperti:
- Tantangan masuk
- Persetujuan pertandingan
- Pembatalan jadwal
- Pengingat jadwal pertandingan

#### Cara menggunakan notifikasi
1. Klik ikon lonceng di bagian atas atau masuk ke menu `Notifikasi`.
2. Baca pesan terbaru.
3. Tandai notifikasi sebagai sudah dibaca jika diperlukan.
4. Gunakan tombol di dalam notifikasi untuk langsung menanggapi challenge.

### 2.9 Logout
Saat selesai menggunakan MATCHGOTIM, keluar dari akun agar data tetap aman.

Langkah logout:
1. Klik avatar atau nama pengguna di pojok kanan atas.
2. Pilih `Keluar`.
3. Pastikan Anda sudah log out sebelum menutup browser di perangkat umum.

## 3. PENUTUP
Panduan ini disusun agar player dapat menggunakan MATCHGOTIM dengan alur yang benar tanpa ada langkah penting yang terlewat.

Selalu gunakan menu `Dashboard`, `Tim Saya`, `Matchmaking`, `Pertandingan`, `Profil`, dan `Notifikasi` sesuai fungsinya. Dengan demikian, pengalaman menggunakan MATCHGOTIM menjadi lebih lancar dan terorganisir.
